# 3D STL Library

Biblioteca de referências para impressão 3D, modelagem no Blender e pesquisa de modelos gratuitos.

> **Importante:** esta é uma curadoria de links, não um espelho de arquivos STL. **Gratuito para baixar não significa liberado para venda** de arquivos ou peças impressas. Verifique a licença de cada modelo na origem. A qualidade geométrica e a aptidão para impressão MSLA ainda precisam ser validadas.

## Atalhos para descobrir mais modelos

Estas são **plataformas de terceiros**, não repositórios GitHub:

- [MyMiniFactory](https://www.myminifactory.com/) — foco em miniaturas, bustos e modelos de resina.
- [Cults3D](https://cults3d.com/) — personagens, estátuas e projetos variados.
- [Printables](https://www.printables.com/) — catálogo de modelos, inclusive gratuitos.
- [Thingiverse](https://www.thingiverse.com/) — grande acervo com qualidade variável.

## Checklist antes de usar um modelo

- [ ] Confirmar autoria, link original e licença (especialmente **uso comercial**).
- [ ] Conferir qualidade visual e detalhes adequados à escala pretendida.
- [ ] Verificar dimensões reais e unidades após importação no Blender.
- [ ] Auditar ilhas desconectadas, bordas abertas e geometria não-manifold.
- [ ] Conferir se peças, encaixes e espessuras são apropriados para impressão em resina.
- [ ] Conferir STL exportado e o arquivo fatiado antes de imprimir.
